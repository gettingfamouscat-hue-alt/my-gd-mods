# Damian's GD Mods

## Fix 100%

Calculate classic-level progress from the player's X position instead of
verification time. Unfinished runs stay below 100%; completed runs show 100%.
Platformer levels use GD's normal calculation.

- Geometry Dash 2.2081, Windows x64
- Geode 5.10.1 or newer
- No extra mod dependencies

[Download Fix 100%](https://github.com/gettingfamouscat-hue-alt/my-gd-mods/releases/tag/fix-100-v1.0.0)
· [Source code](Fix100Percent)

The first release is a test build. The Windows build and calculation tests pass;
gameplay verification is pending. This mod was developed with AI assistance.

## Golden Coin

A Geometry Dash Geode mod by **damian**.

Download the mod from [Releases](https://github.com/gettingfamouscat-hue-alt/my-gd-mods/releases).

## Current build

- Mod ID: `damian.goldencoin`
- Version: `1.0.2`
- Platform: Windows x64
- Geometry Dash: `2.2081`
- Geode: `5.10.1` or newer

On official GD, the mod adds a native golden coin placement tab to the editor. The game's native custom-level coin restrictions still apply.

On Damian GDPS, it also supports the owner's coin tab, pickup effects, collection indicators, and optional secret-coin rewards through compatible GDPS server endpoints.

## Install

1. Download `damian.goldencoin.geode` from the release.
2. Put it in Geometry Dash's `geode/mods` folder.
3. Install the listed dependencies in Geode: Editor Tab API, Node IDs, and ServerAPI.
4. Restart Geometry Dash.

If you use the custom GDPS Rate Button mod, update it to `1.4.17` or newer. Older builds contain the same coin hooks and cannot run alongside Golden Coin.
